在线 Demo：我的麦门周报

下面是真实生成的一份年报（使用仓库内 samples/ 的 16 单脱敏样例数据渲染）。 配置 Token 后同样的命令会换成你自己的真实订单。

它解决什么问题

确定性统计所有口径都是 Python 计算而非模型生成，输入相同输出必相同，可复现才可信。
标签带口径「夜宵常客」会注明夜宵时段占 32%——不输出无法解释的结论。
零 CDN 零 JS单个 .html 文件，双击可开、可邮件发送、可挂 Pages，不产生任何外部请求。
隐私优先样例订单全部脱敏（订单号 OMASK 前缀），有单测防止真实数据误入公开仓库。
