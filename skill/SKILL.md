# 麦门周报

把订单数据变成一份能晒出去的单文件 HTML 年报。

## 命令

```bash
python -m src.cli stats                       # 终端概览
python -m src.cli build --title "2026 麦门年报" --out output/mcd-moments.html
```

报告包含：核心四数、人格标签、时段分布、星期环形图、最常点 TOP5、常去门店、三个片段。

## 硬性规则

1. **只读**：只能调用 `order-list`，禁止任何写操作。
2. **不编数据**：没有的字段就说没有，不得为了图表好看编造数值。
3. **隐私优先**：涉及真实订单时提醒用户这份报告会落到本地，
   如果要发到公开仓库，必须用脱敏样例或自行删除。
4. **人格标签必须带口径**：说「夜宵常客（夜宵时段占 32%）」，不要只丢一个标签。
5. 金额口径说明清楚：取实付金额 `realTotalAmount`。

## 表达风格

数据先行，少形容词。报告已经在视觉上完成了表达，讲解时补充口径即可。
